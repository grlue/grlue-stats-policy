grlue-stats

grlue-stats is a private, internal tool used only by the owner of the TikTok accounts it connects to. It reads the public statistics of the owner's own videos (views, likes, comments, shares) and uses them in internal performance reports.

Terms of Service

  • The tool is used only by its owner for the owner's own TikTok accounts. It is not offered to other users.
  • It only reads data through the official TikTok API with the scopes user.info.basic and video.list. It does not post, edit, delete, message, or follow.
  • Access can be revoked at any time from the TikTok app settings (Security → Manage app permissions).
  • The tool is provided as is, without warranty.

Privacy Policy

  • Data collected: the connected account's basic profile (open ID, username, display name) and the list of its public videos with their IDs, titles, durations, creation times, and view, like, comment and share counts.
  • Use: internal performance reports for the owner's own content only.
  • Storage: stored locally on the owner's computer. Access tokens are kept in a private local file and are never shared.
  • Sharing: data is not sold, shared with, or disclosed to any third party.
  • Other users: no data about other TikTok users is collected.
  • Deletion: revoking the app's access in TikTok stops all collection; locally stored data is deleted on request.
